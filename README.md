# KnotSeedBox 🏴‍☠️⚓

**KnotSeedBox** — это концепт современного веб-интерфейса для приватного BitTorrent-трекера. 

Мы устали от устаревшего дизайна торрент-трекеров из 2008 года, поэтому решили создать красивую, строгую и удобную альтернативу в стиле «Dark Premium UI». В основе философии проекта лежит идея узла (Knot), который надежно связывает пиров и сидов.

## 🎨 Особенности дизайна
*   **Премиальная темная тема:** Глубокий графитовый фон с благородными золотыми акцентами.
*   **Строгая информативность:** Вместо громоздких карточек — аккуратные таблицы в стиле профессиональных дашбордов, где сразу видны сиды, пиры и размер.
*   **Современный UX:** Плавные анимации, модальные окна для быстрого просмотра, живой поиск.

## 🛠️ Технологический стек
*   **Backend:** Python 3, Flask, SQLAlchemy.
*   **Database:** SQLite (для простоты локального запуска).
*   **Frontend:** HTML5, CSS3 (Vanilla), JavaScript (Vanilla), шрифты Google (Cinzel, Inter).

## 🚧 Текущий статус проекта
На данный момент **полностью готов и сверстан фронтенд** (главная страница с каталогом раздач, адаптивная верстка, логика модальных окон и поиска). 
Бэкенд на Flask настроен для вывода базового списка раздач из базы данных.

## 🚀 Как запустить локально
1. Клонируйте репозиторий:
   `git clone https://github.com/ваш-ник/knotseedbox.git`
2. Установите зависимости:
   `pip install -r requirements.txt`
3. Запустите приложение:
   `python app.py`
4. Откройте в браузере: `http://127.0.0.1:5000`
